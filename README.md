# Social Network Graph

## Overview

Social Network Graph is a project that represents relationships between users as a graph structure. Each user is modeled as a node, while relationships such as friendships, follows, or interactions are modeled as edges.

The project helps analyze social connections, discover important users, visualize communities, and understand how information or influence spreads across a network.

## Features

- Represent users as graph nodes
- Represent relationships as graph edges
- Add, remove, and update users
- Add and remove connections between users
- Display the social network graph visually
- Analyze user connections
- Find mutual friends or shared connections
- Detect communities or groups in the network
- Calculate graph metrics such as:
  - Degree centrality
  - Shortest path
  - Connected components
  - Clustering coefficient
